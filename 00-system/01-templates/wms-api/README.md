# WMS 입고현황 자동 조회 도구

OtooWMS(eglogis.otoowms.kr)에 매번 로그인해서 "품목별 입고 리스트"를 수동으로 다운로드하지 않고,
본인 계정으로 명령어 한 줄로 바로 데이터를 가져오는 도구입니다.

## 준비물

- **Node.js** 설치 (18 이상). https://nodejs.org 에서 "LTS" 버전 다운받아 설치하면 됩니다.
- 본인의 **OtooWMS 로그인 아이디/비밀번호** (지금 회사 업무용으로 쓰는 그 계정)

## 처음 1회만 하면 되는 설정

1. 이 폴더(`wms-api`)를 통째로 본인 PC 아무 위치에 복사
2. 폴더 안의 `.env.example` 파일을 복사해서 이름을 `.env`로 바꾸기
3. `.env` 파일을 텍스트 편집기(메모장 등)로 열어서 아래처럼 본인 계정으로 채우기:
   ```
   WMS_USERNAME=mekim
   WMS_PASSWORD=본인비밀번호
   ```
   (예시일 뿐, 본인 아이디/비밀번호로 바꿔서 넣으세요)
4. **이 `.env` 파일은 절대 다른 사람과 공유하거나 회사 공유폴더에 올리지 마세요** — 본인 PC에만 두는 파일입니다.

## 사용법

터미널(명령 프롬프트 / PowerShell)을 열어서 이 폴더로 이동한 뒤:

```
node fetch_inbound.js 2026-07-31 2026-08-02
```

- 첫 번째 날짜: 조회 시작일(입고일자 기준)
- 두 번째 날짜: 조회 종료일(입고일자 기준, 포함)

실행하면:
- 화면에 로그인 결과, 조회 건수, 날짜별 건수, 총 입고수량이 바로 보이고
- 같은 폴더에 `입고현황_20260731-20260802.json` 같은 결과 파일이 저장됩니다.

## 주의사항

- **반드시 "입고일자" 기준으로 조회됩니다** (입고요청일자 아님) — 실제로 창고에 물건이 들어온 날짜입니다.
- 5회 연속 로그인 실패하면 WMS 계정이 잠길 수 있으니, 비밀번호가 정확한지 미리 확인하세요.
- 이 도구는 본인 계정 권한 범위 안에서만 조회됩니다 — 다른 사람 계정을 대신 쓰는 게 아닙니다.

## 재고현황 자동 다운로드 (발주서 검증 도구 연동용)

[[발주서 검증 도구]](../발주서검증도구/발주서검증도구_웹.html)에 매번 WMS 포털에서 수동으로 "화주x창고x로케이션별 재고 리스트"를 다운받아 업로드하지 않고, 아래 명령으로 최신 재고현황을 바로 받을 수 있습니다.

```
node fetch_stock.js
```

- 화주명 "이그니스" 데이터만 필터링해서 저장합니다 (다른 화주 데이터는 파일에 담기지 않음).
- 저장 위치: `10-projects/5. 실시간 재고현황/` 폴더, 파일명 `YYMMDD_HHMM_실시간 재고.xlsx`
- 저장된 파일은 발주서 검증 도구의 "재고현황" 업로드 칸에 그대로 업로드하면 됩니다.
- `verify_stock_file.js`로 방금 만든 파일이 검증 도구가 기대하는 컬럼 위치와 맞는지 재확인할 수 있습니다 (`node verify_stock_file.js`).

## 실시간 재고 다운로드 버튼 (발주서 검증 도구 안에서 바로)

파일을 따로 받아서 업로드하는 것도 귀찮다면, 발주서검증도구_웹.html 안에 있는 **"실시간 재고 다운로드"** 버튼을 쓸 수 있습니다. 이 버튼은 이 PC에서 도는 작은 로컬 서버에게 요청을 보내서 재고를 받아오는 방식이라, 버튼을 쓰려는 사람은 위의 "처음 1회만 하면 되는 설정"(본인 `.env`)을 마친 다음 추가로:

```
node server.js
```

를 실행해서 로컬 서버를 켜두어야 합니다. (`재고현황 로컬 서버 실행 중: http://localhost:8934` 문구가 뜨면 정상 — 이 터미널 창을 닫으면 서버도 꺼집니다.)

**더 간단하게: `재고서버_시작.bat` 더블클릭 한 번으로 끝내기** — 이 파일을 더블클릭하면 (1) `.env`/필요 패키지 확인 → (2) 로컬 서버 실행 → (3) 발주서검증도구_웹.html까지 자동으로 열어줍니다. 매번 터미널을 열 필요 없이 이 파일 하나만 더블클릭하면 됩니다. (`재고서버_시작.bat`은 실제 로직이 담긴 `start-server.ps1`을 실행하는 얇은 실행 파일입니다.)

- 서버를 켜둔 상태에서 발주서검증도구_웹.html을 열고 "재고현황" 칸의 "실시간 재고 다운로드" 버튼을 누르면, WMS 로그인부터 재고 반영까지 자동으로 끝납니다 (파일 저장/업로드 단계 없이 바로 화면 그리드에 채워짐).
- 서버를 안 켜둔 상태에서 눌러도 도구가 깨지지 않습니다 — "로컬 서버 응답이 없습니다" 안내만 뜨고, 기존처럼 파일을 직접 업로드하면 됩니다.
- 이 버튼은 **본인이 로컬 서버를 켜둔 경우에만** 동작합니다. 로컬 서버 설정을 안 한 팀원은 이 버튼 없이 기존 수동 업로드 방식을 그대로 쓰면 됩니다.
- 이 서버는 `localhost`(이 PC 안)에서만 열려있고 외부에서 접근할 수 없습니다. WMS 계정 정보도 이 PC를 벗어나지 않습니다.

## 문의

이 도구 자체를 수정하거나 다른 화면(입고예정 등)도 자동화하고 싶으면 김명은에게 문의하세요.
